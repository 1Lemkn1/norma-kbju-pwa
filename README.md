# Норма — калькулятор калорий и БЖУ (PWA)

Мобильное приложение для расчёта суточной нормы калорий и БЖУ: пол, возраст,
рост, вес, активность, цель, грудное вскармливание и безопасный минимум
1200 ккал. Данные хранятся только в `localStorage`, сервера нет.

## Стек

- React 19 + TypeScript 5.9
- Vite 7 + `vite-plugin-singlefile` (сборка в один HTML)
- Tailwind CSS 4
- Сервис-воркер + web manifest (установка на Android/iOS, работа офлайн)

## Команды

```bash
npm install
npm run dev       # разработка
npm run build     # сборка в dist/
npm run preview   # локальный просмотр сборки
npm run typecheck # проверка типов (tsc --noEmit)
```

## Расчёт

`src/lib/calc.ts` — единственное место с математикой.

1. **BMR** — Харрис–Бенедикт, пересмотр 1984 (Roza & Shizgal), своя версия
   уравнения для женщин и для мужчин. Для похудения вес в формуле —
   желаемый, но не более чем на 5 кг ниже текущего.
2. **Норма поддержания** = BMR × коэффициент активности (1,2 / 1,3 / 1,4).
3. **Цель** — дефицит или профицит 10–20 %, при ГВ +300 ккал.
4. **Порог** — итог не опускается ниже 1200 ккал.
5. **БЖУ** — граммы на кг веса для формулы, отдельно от калорий.

## PWA: как проверить установку на Android

Установка доступна только по **HTTPS** либо по `localhost`/`127.0.0.1`
(исключение для локальной разработки).

Самый быстрый путь с телефона, подключённого по USB:

```bash
npm run build
npm run preview -- --host          # слушает 0.0.0.0:4173
adb reverse tcp:4173 tcp:4173      # телефон увидит localhost:4173
```

Открыть на телефоне `http://localhost:4173` → меню Chrome → «Установить
приложение». Для публикации подойдёт любой статический хостинг с HTTPS
(Netlify, Vercel, GitHub Pages): содержимое `dist/` выкладывается как есть,
пути в сборке относительные, поэтому подпапка тоже работает.

Требования, которые выполняет сборка:

- manifest с иконками 192 и 512 (`any`) и отдельной `maskable` иконкой;
- сервис-воркер с обработчиком `fetch` (кеширует оболочку и ресурсы);
- `start_url`/`scope` внутри домена, `display: standalone`;
- шрифты локальные (`src/assets/fonts`), внешних запросов нет.

При выпуске новой версии увеличьте `CACHE_NAME` в `public/sw.js`
(сейчас `norma-pwa-v2`), чтобы у пользователей обновился кеш.
